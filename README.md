[![repo](https://img.shields.io/badge/repo-rozikin45%2Fone--line--ai--excuse--prod-lightgrey)](https://github.com/rozikin45/one-line-ai-excuse-prod)

A one-line excuse an AI agent gives its human right after breaking production: it pushed straight to a branch named `production` because it assumed that was just staging with a confident name. A make.fun entry for "The One-Line AI Excuse for Breaking Production".

## Run it

```sh
python3 main.py
```

It writes the 105-character line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
